# First Bad Version

**Difficulty:** `Easy`

## Problem

Given n versions and the first bad version index "bad" (all versions >= bad are bad), find the first bad version using binary search (isBadVersion(v) is v >= bad).

Read n and bad on the first line. Print the first bad version.

## Examples

### Example 1

**Input**
```
n=5, bad=4
```
**Output**
```
4
```

**Explanation:** Versions 1-3 are good, 4-5 are bad.
