# Koko Eating Bananas

**Difficulty:** `Medium`

## Problem

Given piles and h hours, find the minimum integer eating speed k so all piles finish within h hours (hours per pile = ceil(pile/k)).

Read n and h on the first line, then n space-separated pile sizes. Print the minimum speed.

## Examples

### Example 1

**Input**
```
piles = [3,6,7,11], h = 8
```
**Output**
```
4
```

**Explanation:** At speed 4, total hours needed is exactly 8.
