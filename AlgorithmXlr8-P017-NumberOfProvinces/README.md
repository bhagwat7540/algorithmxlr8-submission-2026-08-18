# Number of Provinces

**Difficulty:** `Medium`

## Problem

Given isConnected adjacency matrix, return the number of provinces (connected components).

Read n, then the n by n matrix. Print the single integer answer.

## Examples

### Example 1

**Input**
```
3
1 1 0
1 1 0
0 0 1
```
**Output**
```
2
```

**Explanation:** Cities 0,1 form one province; city 2 forms another.
