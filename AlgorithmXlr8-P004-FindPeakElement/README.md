# Find Peak Element

**Difficulty:** `Medium`

## Problem

A peak element is strictly greater than its neighbors (positions before the start and after the end count as negative infinity). Given an integer array nums, return the index of any peak element.

Read n on the first line, then n space-separated integers on the second line. Print the index of any peak element.

## Examples

### Example 1

**Input**
```
nums = [1,2,3,1]
```
**Output**
```
2
```

**Explanation:** Index 2 (value 3) is greater than both neighbors.

### Example 2

**Input**
```
nums = [1,2,1,3,5,6,4]
```
**Output**
```
1 or 5
```

**Explanation:** Both index 1 (value 2) and index 5 (value 6) are valid peaks.
