# Remove Max Number of Edges to Keep Graph Fully Traversable

**Difficulty:** `Hard`

## Problem

Given n and typed edges [t,u,v] (1=Alice, 2=Bob, 3=both), return max removable edges keeping both fully traversable, or -1.

Read n, m, then m edges "t u v". Print the single integer answer.

## Examples

### Example 1

**Input**
```
4 5
3 1 2
3 2 3
3 1 3
1 2 4
2 3 4
```
**Output**
```
1
```

**Explanation:** The redundant type-3 edge [1,3] can be removed.
