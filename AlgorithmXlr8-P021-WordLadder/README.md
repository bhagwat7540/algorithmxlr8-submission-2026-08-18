# Word Ladder

**Difficulty:** `Hard`

## Problem

Given beginWord, endWord, wordList, return the shortest transformation sequence length (one letter change per step), or 0.

Read beginWord, endWord, n, then n words. Print the single integer answer.

## Examples

### Example 1

**Input**
```
hit
cog
6
hot
dot
dog
lot
log
cog
```
**Output**
```
5
```

**Explanation:** hit -> hot -> dot -> dog -> cog, 5 words.
