# Best Time to Buy and Sell Stock with Cooldown

**Difficulty:** `Medium`

## Problem

Given prices, unlimited transactions but a 1-day cooldown after selling, find the maximum profit.

Read n, then n prices. Print the single integer answer.

## Examples

### Example 1

**Input**
```
5
1 2 3 0 2
```
**Output**
```
3
```

**Explanation:** Three rolling states (hold, sold, rest) track the best profit per day.
