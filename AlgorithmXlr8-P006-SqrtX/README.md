# Sqrt(x)

**Difficulty:** `Easy`

## Problem

Given a non-negative integer x, return the square root of x rounded down to the nearest integer.

The returned integer should be non-negative as well, and you may not use any built-in exponent or square root function.

Read x from standard input, and print the floored square root to standard output.

## Examples

### Example 1

**Input**
```
x = 4
```
**Output**
```
2
```

**Explanation:** The square root of 4 is exactly 2.

### Example 2

**Input**
```
x = 8
```
**Output**
```
2
```

**Explanation:** The square root of 8 is about 2.828, rounded down to 2.

### Example 3

**Input**
```
x = 0
```
**Output**
```
0
```

**Explanation:** The square root of 0 is 0.
