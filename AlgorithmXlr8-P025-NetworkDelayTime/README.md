# Network Delay Time

**Difficulty:** `Medium`

## Problem

Given weighted directed edges times, n nodes, source k, return time for a signal to reach all nodes, or -1.

Read n, m, k, then m edges "u v w". Print the single integer answer.

## Examples

### Example 1

**Input**
```
4 3 2
2 1 1
2 3 1
3 4 1
```
**Output**
```
2
```

**Explanation:** Dijkstra from node 2; the farthest node (4) takes 2 minutes.
