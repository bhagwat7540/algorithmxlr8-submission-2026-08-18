# Course Schedule

**Difficulty:** `Medium`

## Problem

Given numCourses and prerequisite pairs [a,b] (b before a), return true if all courses can be finished.

Read numCourses, then m, then m pairs "a b". Print true or false.

## Examples

### Example 1

**Input**
```
2
1
1 0
```
**Output**
```
true
```

**Explanation:** No cycle; course 0 then course 1.
