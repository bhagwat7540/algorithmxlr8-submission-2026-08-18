# Best Time to Buy and Sell Stock III

**Difficulty:** `Hard`

## Problem

Given prices, find the maximum profit using at most two transactions.

Read n, then n prices. Print the single integer answer.

## Examples

### Example 1

**Input**
```
8
3 3 5 0 0 3 1 4
```
**Output**
```
6
```

**Explanation:** Buy at 0, sell at 3, then buy at 1, sell at 4, total profit 6.
