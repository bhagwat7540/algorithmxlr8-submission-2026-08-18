# Longest Common Subsequence

**Difficulty:** `Medium`

## Problem

Given text1 and text2, return the length of their longest common subsequence.

Read text1, then text2. Print the single integer answer.

## Examples

### Example 1

**Input**
```
abcde
ace
```
**Output**
```
3
```

**Explanation:** The subsequence "ace" is common to both, length 3.
