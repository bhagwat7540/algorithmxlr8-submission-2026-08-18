# Search in Rotated Sorted Array

**Difficulty:** `Medium`

## Problem

Given a rotated sorted array nums (distinct values) and target, return its index, or -1, in O(log n).

Read n on the first line, then n space-separated integers, then target. Print the index.

## Examples

### Example 1

**Input**
```
nums = [4,5,6,7,0,1,2], target = 0
```
**Output**
```
4
```

**Explanation:** 0 is at index 4 in the rotated array.
