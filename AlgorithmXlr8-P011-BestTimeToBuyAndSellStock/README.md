# Best Time to Buy and Sell Stock

**Difficulty:** `Easy`

## Problem

Given an array prices where prices[i] is the price of a stock on day i, find the maximum profit achievable by choosing a single day to buy and a later single day to sell.

If no profit is possible, return 0.

Read n on the first line of standard input, then n space-separated prices on the second line. Print the maximum profit to standard output.

## Examples

### Example 1

**Input**
```
6
7 1 5 3 6 4
```
**Output**
```
5
```

**Explanation:** Buying on day 1 (price 1) and selling on day 4 (price 6) gives a profit of 5, the best possible.

### Example 2

**Input**
```
5
7 6 4 3 1
```
**Output**
```
0
```

**Explanation:** Prices only ever decrease, so no profitable transaction exists, giving 0.
