# Longest Increasing Subsequence

**Difficulty:** `Medium`

## Problem

Given nums, return the length of the longest strictly increasing subsequence.

Read n, then n values. Print the single integer answer.

## Examples

### Example 1

**Input**
```
8
10 9 2 5 3 7 101 18
```
**Output**
```
4
```

**Explanation:** Subsequence 2, 3, 7, 18 (or 101) has length 4.
