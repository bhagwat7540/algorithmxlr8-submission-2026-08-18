# Find the Town Judge

**Difficulty:** `Easy`

## Problem

Given n and trust pairs [a,b] (a trusts b), find the town judge (trusted by all, trusts none), or -1.

Read n, m, then m pairs "a b". Print the single integer answer.

## Examples

### Example 1

**Input**
```
2 1
1 2
```
**Output**
```
2
```

**Explanation:** Person 2 is trusted by 1 and trusts no one.
