# Binary Search

**Difficulty:** `Easy`

## Problem

Given sorted nums and target, return the index of target, or -1, in O(log n).

Read n on the first line, then n space-separated integers, then target. Print the index.

## Examples

### Example 1

**Input**
```
nums = [-1,0,3,5,9,12], target = 9
```
**Output**
```
4
```

**Explanation:** 9 is at index 4.
