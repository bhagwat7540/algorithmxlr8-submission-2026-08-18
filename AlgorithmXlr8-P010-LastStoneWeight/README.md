# Last Stone Weight

**Difficulty:** `Easy`

## Problem

Given an array of stone weights, repeatedly smash the two heaviest together (destroying both if equal, otherwise replacing them with their weight difference). Return the weight of the last remaining stone, or 0 if none remain.

Read n on the first line, then n space-separated integers. Print the final weight.

## Examples

### Example 1

**Input**
```
stones = [2,7,4,1,8,1]
```
**Output**
```
1
```

**Explanation:** Repeated smashing eventually leaves one stone.
