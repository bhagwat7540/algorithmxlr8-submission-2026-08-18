# Course Schedule II

**Difficulty:** `Medium`

## Problem

Given numCourses and prerequisite pairs [a,b] (b before a), return one valid course order, or an empty array if impossible.

Read numCourses, then m, then m pairs "a b". Print the order space-separated, or an empty line if impossible.

## Examples

### Example 1

**Input**
```
2
1
1 0
```
**Output**
```
0 1
```

**Explanation:** Course 0 before course 1.
