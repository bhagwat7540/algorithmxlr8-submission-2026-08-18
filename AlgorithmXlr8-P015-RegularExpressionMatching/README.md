# Regular Expression Matching

**Difficulty:** `Hard`

## Problem

Given s and pattern p (with "." and "*"), determine if p matches the entire string s.

Read s, then pattern p. Print true or false.

## Examples

### Example 1

**Input**
```
aa
a*
```
**Output**
```
true
```

**Explanation:** "a*" matches zero or more "a"s, covering "aa".
